# Customer Shopping Behavior Analysis

A data analysis project focused on understanding **customer shopping behavior, purchasing patterns, discounts, subscriptions, product performance, and customer segmentation** using Python, Pandas, and MySQL.

📌 Project Overview

This project takes customer shopping data and performs data cleaning, transformation, and analysis.

The workflow is:

Raw Customer Data
       ↓
Python + Pandas
       ↓
Data Cleaning & Transformation
       ↓
MySQL Database
       ↓
SQL Analysis
       ↓
Business Insights


The project was created to practice real-world **Data Analyst workflows**, especially working with Pandas and SQL together.

🧹 Data Cleaning & Preparation

The dataset was prepared using Pandas before being transferred to MySQL.

Missing Values

Missing Review Rating values were filled using the **median rating of their respective product category**.

This uses Pandas groupby() and transform() so that each missing value receives the median of its category.

### Column Name Cleaning

Column names were converted to lowercase and spaces were replaced with underscores.

For example:

```text
Purchase Amount (USD)
```

was converted to:

```text
purchase_amount
```

### Age Group Segmentation

Customers were divided into four age groups using Pandas `qcut()`:

* Young Adult
* Adult
* Middle-aged
* Senior

### Purchase Frequency

Text-based purchase frequencies were converted into the approximate number of days between purchases.

For example:

```text
Weekly → 7
Fortnightly → 14
Monthly → 30
Quarterly → 90
Annually → 365
```

### Redundant Column Removal

The `promo_code_used` column was removed after checking that it contained the same information as `discount_applied`.

## 📊 SQL Analysis

The project contains SQL queries answering several business questions.

### 1. Revenue by Gender

Calculates the total purchase revenue generated by each gender.

### 2. Discounted Purchases Above Average

Identifies customers who used a discount but still spent more than the overall average purchase amount.

### 3. Top Products by Review Rating

Finds the top 5 products based on their average review rating.

### 4. Shipping Type Analysis

Compares the average purchase amount for Standard and Express shipping.

### 5. Subscriber vs Non-Subscriber Analysis

Compares:

* Number of customers
* Total revenue
* Average spending

between subscribers and non-subscribers.

### 6. Discount Dependency by Product

Identifies products with the highest percentage of purchases made using discounts.

### 7. Customer Segmentation

Customers are categorized based on their previous purchases:

```text
1 previous purchase       → NEW
2–10 previous purchases   → RETURNING
More than 10              → LOYAL
```

### 8. Top 3 Products in Each Category

Uses a **CTE and `ROW_NUMBER()` window function** to find the three best-selling products within each category.

### 9. Repeat Buyers and Subscriptions

Analyzes subscription status among customers with more than 5 previous purchases.

### 10. Revenue by Age Group

Calculates the total revenue contributed by each age group.

### 11. Category Performance

Calculates total purchase amount and average review rating for each product category.

## 🚀 How to Run

### 1. Install required Python packages

bash
pip install pandas sqlalchemy pymysql


### 2. Start MySQL

Create the database:

sql
CREATE DATABASE customer_behavior;


### 3. Run the Jupyter Notebook

Load the customer dataset and perform the cleaning and transformations.

### 4. Connect Python to MySQL

SQLAlchemy is used to establish the connection between Python and MySQL.

### 5. Upload the DataFrame

The cleaned DataFrame can then be stored as the `customer` table.

### 6. Run the SQL queries

Open:

customer behaviour sql.sql

and execute the analysis queries against the `customer` table.
